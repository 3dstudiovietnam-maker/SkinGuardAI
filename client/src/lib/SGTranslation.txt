SGTranslation.txt — CONTENT REMOVED (compliance cleanup)

This file used to hold a full 11-language snapshot copy of client/src/lib/translations.ts.
It was imported by nothing (verified by grep across client/, server/, api/ and scripts/),
it is a .txt so it never entered any bundle, and it had drifted badly: it still carried the
PRE-CLEANUP marketing copy that has since been removed from the live translation table.

What it contained, in all 11 languages, and why it had to go:

  * hero.accuracy / hero.aiAccuracy — a hard-coded model-accuracy percentage
  * faq.fa_a1 / faq.gs_a1           — the same percentage repeated as a prose claim
                                      ("SkinGuard AI achieves <N>% ... in detecting
                                      potential skin changes")
    -> SkinGuard AI has never run an accuracy validation study. The figure was invented.
       Unsubstantiated health-efficacy claim (FTC substantiation, App Store 1.4.1).

  * social.title / social.subtitle  — a headline asserting the app was trusted by, and
                                      inviting the reader to join, many thousands of users
  * auth.signUpSubtitle             — the same user-count framing on the sign-up screen
    -> The app has no verified user base of that size. Fabricated social proof.

  * abcde.subtitle                  — wording implying the detection is professionally
                                      endorsed/backed by dermatology
    -> No dermatologist has endorsed the app. The live table now states that the ABCDE
       method originates with dermatologists, which is true, rather than implying the
       app itself carries professional backing.

The full original text is preserved in git history:
    git show HEAD:client/src/lib/SGTranslation.txt

DO NOT restore this file as a translation source, and do not copy strings out of git
history into translations.ts — that is exactly how the invented accuracy figure leaked
into scripts/update-translations.cjs and survived there for months.
The single source of truth is client/src/lib/translations.ts.
